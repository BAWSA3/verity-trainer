## Strategic frame — don't match, reframe

Luka and Shiny need cash/prize giveaways because their product has no intrinsic value curve. VERITY has one: the VCC + Digital Twin appreciate as platform credibility compounds. So we pay the habit layer in **native currency** — authentication credits, pool previews, Twin insurance, grail raffles — not dollars. Structurally cheaper, more sticky, on-brand.
